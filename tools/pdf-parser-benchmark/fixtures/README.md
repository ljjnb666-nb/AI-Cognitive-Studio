# Fixtures

Real PDF fixture files are **never committed** (Phase 1 spec #22). They live in:

```
D:\ai-cognitive-pdf-benchmark-data\fixtures\
```

`fixtures.manifest.json` in this directory is the committed copy of the
manifest (ids, classes, generator, declared page counts) — metadata only.

Synthetic fixtures are generated by `scripts/make-fixtures.mjs`:

| id | class | generator summary |
| --- | --- | --- |
| F1-native-cn | native-cn | 5 pages, synthetic Chinese paragraphs (embedded CJK font) |
| F2-multicolumn | multicolumn | 4 pages, two-column English text |
| F3-scanned-cn | scanned | 3 pages, rasterized Chinese text images (no text layer) |
| F4-textbook-complex | textbook | headings + ruled table + vector figure + footnotes |
| F5-long-book | long-book | 520 pages of synthetic English text |
| warmup | warmup | 2-page document for untimed model preload |
| not-a-pdf | malformed | plain text with a .pdf extension (failure-isolation test) |

Real (user-provided, legally sourced) fixtures may be added to the same
directory and registered in the manifest — the harness reads paths only from
the manifest allowlist.
