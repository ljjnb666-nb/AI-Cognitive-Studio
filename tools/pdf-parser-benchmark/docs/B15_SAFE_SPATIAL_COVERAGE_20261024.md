# B15 v5 私有 OCR 与图像候选：最小化公开统计门禁

## 为什么要做

上游 #170 已在真实 Windows 上验证 19 条 OCR 文字框与图像区域的几何归属，并生成本地 v5 JSON + PNG。但公共日志不能打印真实 OCR 文本、坐标、图书页、图片及完整来源 SHA，因此此前无法从公有 CI 得到“落入候选 ROI、仅部分重叠、区域外”的实际数量。

本切片以**仅一次重算、只读、只输出三项整数**的方式补足该缺口。这是判定空间覆盖的工程统计，不是识别准确率或图例语义评分。

## 严格证据约束

- 使用相同源页 PNG、MinerU Markdown、冻结 v1/v3/v4（包括 v4 overlay）重新构造 v5 对象，并和现有冻结 v5 做规范字节比较。拒绝单独相信可伪造的 `spatial_bucket_counts`。
- 要求 B15 第 109 物理页、图 1-4-16、19 条、来源哈希和所有 authority=false、CER=null 与 frozen v5 一致。
- 只允许公开三项非负整数：`ACS_B15_V5_INSIDE`、`ACS_B15_V5_PARTIAL`、`ACS_B15_V5_OUTSIDE`，三项必须恰好合计 19，数值不代表语义正确性。
- 未知异常只打印固定 `ACS_B15_V5_COVERAGE=REJECTED`，不打印堆栈、私有路径、OCR 文字、单个四点框、图像数据、源 SHA；不生成公开 Artifact。
- 严格只读，不重新跑 OCR/视觉模型，不联网，不改私有源、不覆盖 v1-v5，不触动生产服务。

## 门禁与下一步

Ubuntu 只跑合成且无版权内容的白名单防泄漏测试；owner-only Windows 使用已冻结的 D: v5 做真实来源重算与安全整数输出。最后核对该准确 HEAD 完整主 CI。

**类别不是图例识别结论：** INSIDE 意味着 OCR 行的轴对齐包围框主要落在算法生成且尚未独立确认的图像 ROI 内，不代表其是曲线标签、真实图例或正确识别字符。#161 的独立 gold、图内四类符号、曲线关系、CER 仍 UNVERIFIED，主解析路由不可据此冻结。所有 PR 保持 Draft/Open/Unmerged。
