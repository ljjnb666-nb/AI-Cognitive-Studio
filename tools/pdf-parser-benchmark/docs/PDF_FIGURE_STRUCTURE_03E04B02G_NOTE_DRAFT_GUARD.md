## 发现的问题
原审核页中，节点/关系的文本备注只在 `change`（通常输入框失焦）时写入内存草稿。持续键入却未离开输入框的备注，不会立即增加 `localEditSerial`，可能绕过草稿切换前的安全判断；浏览器刷新/关闭也缺少原生脏草稿提示。这不是可通过原 02F CI 成功排除的输入时序。

## 修复边界
1. 在每次备注 `input` 事件中立即验证并更新内存草稿，触发既有 450ms 防抖、CAS/失败留草稿机制；不在每次按键后重绘输入框，以保护输入焦点。
2. 浏览器关闭/刷新前，若存在未保存修改或在途 CAS 写入，则调用标准 `beforeunload` 保护。浏览器是否展示确认框仍由浏览器策略决定，不能承诺强制阻止退出。
3. 新增真实 Edge 合成回归：未失焦输入备注 -> 脏状态阻止跨区域导航 -> 页面退出保护 -> 本机合成草稿最终持久化，且 `graphVerified=false`。
4. 扩大**仅合成** Edge 门禁的 PR 目标分支范围至 02F，仍仅允许本仓库所有者及特定分支，严格不读取 D 盘真书、不调用付费模型。
