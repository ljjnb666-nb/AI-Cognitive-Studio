# AI Cognitive Studio｜B15 OCR 行序分区与顺序差异二次诊断

**基线**：已验收 Draft #148，B15 原始 PDF **物理第 109 页**，RapidOCR 32 条 OCR 行。既有回执显示其中 14 行无 3-gram 片段匹配、2 行低匹配、8 行片段太短、8 行高匹配。此事实**不代表 MinerU 识别失败，也不是人工真值**。

## 新增问题与测量

1. 从 D: 私有目录重新只读审核 #148 不可变诊断回执、#145 五书同源回执及 SHA 固定的原始 B15 OCR 文本 / MinerU Markdown。任何上游文件被更改都会拒绝执行。
2. 按 RapidOCR 返回的**第 1～4 行序区段**（共四个，按行索引而非真实空间坐标）输出各区段行数、零/低片段匹配行数、过短行数。**这不是纸面左上/右下四象限**，亦非真实页面布局识别。
3. 将双方文本应用相同的 NFKC、大小写折叠、剔除图片 Base64 和保留数字/字母规范。测量：
   - **字符多重集合交集（unordered shared characters）**：两边共有多少个字符，不考虑字符位置和顺序，重复字符只按最少出现次数计入。
   - **最长公共子序列 LCS（ordered LCS）**：在不变更字符先后顺序情况下的最大共有字符数，可有跳跃。
   - **顺序差距（unordered - ordered）**：同样的字符存在于两个结果中，但无法全部按照同一顺序对齐的数量。正值可能提示阅读顺序/版面变化，也可能来自替换、遗漏或重复内容；不构成根因或准确率证明。
   - 可读比例都以**两种规范化输出中较短的一方字符量**为分母；这是不同引擎之间的对照，不是 CER、WER、文本准确率、缺字率或 OCR 召回率。
4. 全程动态规划使用精确 LCS、内存 O(较短侧长度)，限制最长 5000 字符和最多 200 万比较单元，越限明确拒绝，绝不截断悄悄输出似是而非的分数。
5. 结果仅含匿名数值和旧源 SHA，**不包含原书文字、可识别的 OCR token / 3-gram、截图、坐标、Base64、Markdown、个人目录或其他内容**。公开 GitHub CI 仅显示上述匿名汇总；详细回执保存在本地 D: 私有目录。

## 风险与后续边界

LCS 较低不能证明 MinerU 漏字，字符集合差距或多个短行也不能证明 RapidOCR 正确。下一步根据四区段的匿名计数决定需要看哪块**私有原页**，另行评估其文本流、图表、公式与方向。只有独立参考才可求 CER，且用户无需事先人工审所有页；机器生成的 OCR 不能自称独立金标准。

这轮不增加模型调用、不下载权重、不上传书页、不修改既有私有证据、不合并任何 stacked Draft PR。
