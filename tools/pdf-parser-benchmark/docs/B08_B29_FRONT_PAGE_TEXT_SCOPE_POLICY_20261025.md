# Stage 1｜B08/B29 原始物理页的评分口径 v1

本文件修复五书参考答案签发前的**范围分歧**，不声明任何页已签发完整 gold。

## 双范围、不交叉补字

统一按照**同一物理页正面**实际可见的印刷字符编制来源证据。上一页续句只能包含本页看得见的部分，不能补上不可见上文；背面透印不作为本页的 OCR 目标；语言不通顺但源图确实印出的字一律原样保留，不用 OCR 共识或模型语义改错。

独立列出两种评分视角（最终需要同源参考且 OCR 引擎使用同一范围）：

- `reading_content`：正文和正文内提示栏及标题，用于衡量用户实际阅读到的知识内容。
- `front_printed_text`：前者加上正面印刷页眉、栏目标识和页码，衡量完整可见正文及页面元文字。它**不等于**任意图表语义已核验。
- 装饰性背景字、图片里用于表达语义的图形文字，以及反面透印**不混入上述两项 CER**，而是列出单独 visual-text fidelity 问题；不能简单把未分类内容静默忽略。

| 页面 | reading_content 块数 | reading_content 草稿字符（含标点） | front_printed_text 块数 | front_printed_text 草稿字符（含标点） |
|---|---:|---:|---:|---:|
| B08 物理 p64 | 5 | 220 | 7 | 235 |
| B29 物理 p72 | 5 | 462 | 7 | 484 |

以上是**来源转录候选的字符统计**，不是 CER，更不是已认证来源全文。B08 的提示栏包含在正文阅读范围，页眉与印刷页码只在完整印刷文字范围。B29 的淡色正式页眉和 `2－057` 栏目页码只在完整印刷文字范围；背景装饰英文 `PART` 明确保留为单独的视觉装饰文字事实，**不算阅读正文，是否属于原页全部文字召回需另设视觉指标**。B29 页码中横划字符形制仍有待核准，不能因为口径已定而隐去此项风险。

## 实现边界与保护

纯函数 `ebook_fivebook_text_scope.py` 接收来源视觉分块的类型、字符与标点数，fail-closed 校验；输出两个范围的 block IDs、字符统计与私有文本摘要，**不调用 OCR 引擎，不生成 reference 的 external approval，不计算任何 CER**。所有正式 `independently_approved` 均为 false、CER 为 null；当某类区块未知、跨页或透印未标注时应拒绝作为评分输入。

测试全部使用合成英文字词和标点，没有原书正文、私有 SHA、图像或坐标。来源块级 v5/v6 私有审阅文件留在当前用户会话与 D: 私有数据域，不推向 GitHub。原始图像 v3 用户 Windows `BYTE_MATCH` 不等于独立全文/标点/图形语义已被核准。

## 架构选型的退出口径

第一阶段最终通过必须逐一证明五书各页的来源全文边界、页眉和装饰的分类、实际完整逐字及标点阅读顺序、外部独立来源真值。只有确定每一条引擎抽取出的文本同属某一范围，第二阶段才允许比较对应 CER，否则继续显示 null 并额外记录 coverage mismatch。图像、公式、表格与曲线语义另行评测，不能用 CER 替代。
