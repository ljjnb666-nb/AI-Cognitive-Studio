# 03E-04B-02D｜集中接收状态面板：无人值守检测、最终人工审核

**日期：2026-10-21，PR #100 Draft/Open/Unmerged**

## 目标与交付

原审核工作台现新增“**模型结果集中接收状态（自动只读核验）**”区域。用户通过原来的本机临时 token 打开 `graph-review.html`，页面自动执行固定 GET `/api/private-graph/intake/overview`，可手动按“重新核对模型结果”刷新。所有信息在单页集中呈现，不需要单独指定每个文件路径或逐本查目录。

展示的五类关键状态为：**已登记、等待人工复核**；**来源已核验但尚未批准登记**；**只有图片、尚未授权付费识别**；**历史请求结果不确定、禁止重发**；**模型结果异常、须人工排查**。这些区分严格复用 03E-04B-02C 的后端安全来源校验，不因 PNG 或文件名存在而假定图关系正确。

浏览器端校验响应 schema、权限属性、各类计数之和、固定书籍 ID、规范页码/region、去重、来源状态、节点/边数量和 `graphVerified=false`、`humanVerified=false`、`dispatchEnabled=false`。使用 `textContent` 构造 DOM，不向界面注入返回内容 HTML。**状态区没有批准、付费调用或自动登记按钮**。服务器继续只读响应脱敏 ID、状态和计数，不返回原图、节点文字、API Key 或文件路径。

### 明确未实现

当前仍没有真实云端收费执行器、账户价格上限保证、经过真正操作员身份授权的执行许可，也没有自动把完整 GLM 结果提升为**代码注册**及正式图谱认证的权限。将来机器结果可在来源 SHA 核验后形成注册候选，但要进入通用正式审核，仍需独立的可信登记批准。最终人工图谱复核不会被绕过。
