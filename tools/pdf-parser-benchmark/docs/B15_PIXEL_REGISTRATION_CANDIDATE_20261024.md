# B15 图 1-4-16 原图像素位置候选 | 来源与证据边界

本工作仅在 Windows 私有 D: 保存原页 PNG、MinerU Markdown 与 v1 图文阅读顺序回执，**不公开任何原书页面、文字、像素坐标、完整 SHA、图例曲线对应关系**。

基于 v1 真实来源 SHA 固定，将 MinerU Markdown 的第二张 JPEG 用离线 OpenCV/Pillow 与 B15 物理第 109 页的原始 PNG 做有限尺度/旋转模板匹配，输出少量像素候选区域。结果存储为私有 v2 JSON，使用 O_EXCL 首创与后续完整重算 --audit-only 检测漂移；图例符号、曲线、OCR 准确率和源像素到 OCR 四边形的转换均保持 UNVERIFIED。候选匹配分数不是正确概率。

无法读到匹配 SHA、缺本地离线依赖、图像预算超限、低对比图像、私有报告损坏均必须失败，不会自动填补。公有 GitHub 仅保留无原书数据的合成测试与匿名状态日志；Windows 真机不新装模型或调用云服务，历史文件不会覆盖。

**验收边界**：真实 Windows workflow 全绿仅代表候选可计算且私有报告稳定，不意味着图像位置已经独立验证，更不意味着图例符号与曲线已经对应。后续必须以原书像素可视化核对、独立标注或来源证明完成区域确认，再确定 OCR 四边形到像素的位置变换，才能谈图表语义裁决。当前没有独立 gold、没有 CER，生产识别架构 NOT_FROZEN。

这是一条独立研发 Draft，基于 #165 的真实来源 v1，不修改任何生产解析语义，不擅自合并 #165 或 #167。
