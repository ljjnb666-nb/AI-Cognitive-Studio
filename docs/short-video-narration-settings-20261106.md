# 短视频旁白配置及就绪状态修复

## 根因

短视频执行要求语音模型及独立的旁白音色、版本、语速、音调、输出格式。原表单只有语音模型绑定；状态卡只展示三个模型依赖，却在总状态中另外检查旁白，造成三个勾与“未完成”并存。

## 修改

- 短视频语音用途新增单人旁白音色、语速输入，WAV 输出、默认音调 0；保留既有版本及其他用途参数。高级 JSON 仍可显式编辑，不与表单叠加。
- 服务端保存、短视频执行就绪检查共用旁白校验。智谱仅允许适配器已支持的音色、0.5～2 倍语速、WAV、音调 0 和无额外风格；OpenAI 沿用 0.25～4 倍语速且不支持非零音调。模型格式仍经过原 Gateway 能力校验。
- 配置错误返回明确中文提示，拒绝请求且保留旧记录。
- 服务状态新增“旁白设置”第四项，显示 3/4 或 4/4；提供“设置短视频旁白”入口，跳转并展开对应配置。
- 不自动替用户选择音色，不修改现有数据库绑定或冻结任务；原有未完成旁白须由用户选音色并保存。

## 验证

- 独立 PostgreSQL 测试库及表单测试：4 文件、70 项通过。覆盖旧模型绑定但缺失旁白时 3/4、合法保存后 4/4、非法音色、缺失字段、语速、格式、音调拒绝且保留旧记录、旁白版本及其他设置保留。
- 首轮新增错误提示测试误按嵌套对象断言，而真实 API 使用字符串错误码。修正测试以遵循现有接口后全部通过，未变更真实错误契约。
- TypeScript、变更文件 ESLint、Git 空白检查通过。
- Browser 插件不可用，按前端测试调试技能使用 Playwright 验证实际组件与模拟接口：缺项提示可见，入口跳转正常，选择小陈和 1.25 倍速后保存请求字段完整，卡片变为 4/4。数据库测试独立验证真实保存及就绪逻辑。
