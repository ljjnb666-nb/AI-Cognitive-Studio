# AI 深度理解进度展示

## 行为

- 书籍处理状态新增分块进度条、已保存分块数/总分块数、百分比和中文阶段。
- 计数来自详情读取中当前正式提取所对应最新 BookAnalysisRun 的 CHUNK 成果数量与其 ChunkSet 分块数量，不使用时间估算，不按供应商调用次数计数。
- 分节、章节、全书综合、结果整理、检索索引、核验保存分别显示中文阶段。分块 100% 时仍明确说明全书归并、综合和核验可能尚未完成。
- 无分块总数时显示准备状态；失败后保留已保存计数。其他任务、其他阶段成果及非当前提取的 Run 不混入计数。
- 详情页和处理状态 API 返回同一进度投影。沿用现有活动任务约 7.5 秒的 router.refresh，不增加轮询通道或模型请求。
- 保留原有固定屏幕/内容区内滚动布局，无 Worker、预算、执行身份或数据库结构变更。
