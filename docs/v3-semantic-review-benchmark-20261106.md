# v3 逐项语义审校真实样本基准（2026-11-06）

本轮在 Draft PR #239 集成分支上，用真实电子书、真实付费模型与人工独立 Gold 完成了 v3 逐项摘要审校的首轮真实质量核验。全部原始证据、逐案回执与费用台账保存在私有 Benchmark 目录（含版权原文，不进入公开仓库）；本文只保留脱敏指标与结论。

## 基准设计

- 来源：既有 141/141 分块隔离全书 Run 的真实修订候选及其人工逐句审计（15 项摘要论断 S01–S15）。
- Gold：人工按原文块逐句标注，不参考任何被测模型输出。8 组基准修订共 67 条原始句行，经验证器拆分后计分为 68 个原子：42 正例、26 负例；负例含最小改动困难负例（数字/年份/方向/主体单点扰动）、观点误作事实、预测写成既成、历史推广、因果颠倒、合理虚构、来源误归属、单句多事实、跨章节因果捏造、摘要内提示词注入、比原文更强的不可判定断言等。
- 复用既有 47 跨度证据池坐标；所有坐标在隔离库中重新校验，证据摘录 SHA-256 与人工审计一致。
- 双库双臂：分析模型为 MiniMax-M3 的候选由独立模型审校；另建分析身份为智谱的镜像基准库，使 MiniMax-M3 可作为审校方（跨模型对照的合法任务，不绕过独立性门禁）。

## 发现并修复的三个协议缺陷（v1 字节级不变）

1. **v3 证据包随原子数×证据跨度线性放大**：16 原子 × 47 跨度的真实候选包达 72.4K 字符，超过 72,000 硬限，v3 在生产规模必然 fail-closed（v2 同输入仅 12.7K）。修复：`sourceExcerpts[i]` 携带坐标与原文一份，各原子 `evidence` 改为索引列表，同输入降至 15.5K。
2. **回执要求回显 `evidenceBundleHash`，但 v1/v2 输入从未携带该值**：真实模型只能猜（实测 MiniMax-M3 抄成了 `revisionHash`），任何真实审校都会被 `BOOK_MODEL_REVIEW_INVALID` 拒绝——此前该缺陷被 glm 的 LENGTH 截断掩盖。修复：v2/v3 证据包内嵌该承诺字段（对该字段以外的包内容取哈希，回放可复算）；v1 保持冻结。全库核查确认不存在任何历史 modelProof 回执，故无历史兼容性破坏。
3. **16,384 输出上限对生产规模不足**：M3 adaptive 在 16 原子 × 47 跨度正控上耗满 16,384 token 全部用于思考（finish=LENGTH，按规拒收）。修复：v2/v3 上限提升至 32,768；实测该案 26,587 输出 token 完成收据。另在 v2/v3 提示词钉死 `notes/reason` 必须为字符串（实测 MiniMax 曾返回数组导致整笔回执作废）。

关键观察：

- **有效回执与原始响应须区分**：M3 两臂的有效回执未出现原子错误支持或整案错误放行；GLM 的一份不合规原始响应曾将一处时间语境数字错误判断为 SUPPORTED，但被协议拒收，未形成有效发布回执。两条摘要内嵌提示词注入均被 M3 拒绝。
- **v3 的价值在定位而非案级准确率**：v2 与 v3 在本 Gold 上案级结论相同（正控均因同一边界句被 BLOCKED），但 v3 给出逐原子判定与引用，把问题定位到具体句子（本例为教师岗位句的因果表述边界）；v2 只能整案拒绝。
- **误拒集中于两句边界抽象表述**（S09 因果措辞、S01 抽象概括）：方向保守（宁拒不放），对门禁安全但推高人工复核量，需在 Gold 中标注为边界样本。
- **adaptive 思考有可测质量收益**：disabled 误拒 17.9% vs adaptive 4.8%，引用命中与语义把握同步下降；adaptive 成本约 3 倍、时延约 6 倍。不支持为省钱默认关闭思考。
- **长 ID 抄写偶发失真**：16 原子规模下 M3 曾将 25 字符 `sourceBlockId` 抄错 1 字符，回执被严格校验拒绝（fail-closed 正确）；复跑未复现。严格校验必须保留。
- **glm-4.7-flashx 目前不满足审校收据契约**：响应 `schemaVersion` 错抄、引用用字符串拼接格式、语义上存在 1 处原子级误判 PASS（时间语境数字）；glm-4.7-flash 探针被供应商 429 限流。独立审校槽需要模型资格验收，不能假设任意 OpenAI 兼容模型可用。
- **次要网关缺陷**：`ProviderAdapterFailure`（如 RATE_LIMITED）经 `safeError` 包装后错误码退化为 `INTERNAL_PROVIDER_ERROR`，影响诊断与分类，建议后续修复。

## 真实生产候选结论

历史候选 `394f9b8f…`（分析模型 MiniMax-M3）本轮仍无法获得合格独立审校：glm-4.7-flashx 契约不合规、glm-4.7-flash 被限流，MiniMax-M3 受独立性门禁正确阻止。**SEMANTIC_REVIEW 维持 BLOCKED**；该候选的放行需先完成独立审校模型资格验收（建议以本基准 Gold 作为资格测试集）。

## 建议

1. v3 质量已达到受控推广条件，但建议保持显式启用（`atomizeSummary: true`）一个观察期：误拒 4.8% 集中于边界表述，先在人工复核工作流中消化。
2. 独立审校槽增加模型资格门禁：任何模型进入 BOOK_SEMANTIC_REVIEW 前须通过本基准 Gold 的资格测试（契约合规 + 拦截率 + 零 False PASS）。
3. 后续修复 `safeError` 错误码遮蔽，并考虑对超长 ID 抄写失败的单次重试策略（仅限未消费回执且失败原因为 ID 失真时）。
4. 原子化拆分仍为确定性标点边界：单句多事实在 v3 中是一个原子（本基准中模型在 5/6 该类负例上仍正确拒绝）；真正的语义原子化（一句多事实拆分）留待后续版本评估。
