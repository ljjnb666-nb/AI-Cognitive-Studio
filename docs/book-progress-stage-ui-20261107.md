# 分块完成与全书阶段显示修复

用户看到278/278块及100%，但任务仍在全书综合。旧百分比确实仅统计CHUNK成果，不代表全书成功。旧计时使用BookAnalysisRun首次startedAt，跨多次恢复累计563分钟，错误表达成本次持续执行。

## 修改

- 分块进行中仍显示明确标注的分块百分比。
- 分块完成进入后续阶段后，显示“分块理解已完成 · 278/278块”，不再展示醒目的100%满格条；活动阶段显示不定进度及具体阶段，停止状态不显示活动进度条。
- 第三步骤与处理中说明显示实际阶段，例如“正在全书综合”。不估算或伪造全书百分比。
- 计时优先使用当前executionClaimedAt或当前Job.startedAt；排队按当前Job.createdAt计时。旧数据缺字段时兼容回退，不改写历史时间。
- 列表、详情及轮询共享同一状态投影和计时规则。
