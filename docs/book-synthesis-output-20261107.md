# 全书综合输出截断修复

## 真实原因

当前任务278/278个CHUNK已完成，失败阶段为BOOK_SYNTHESIS。失败回执报告输入4820、输出16000词元，HTTP 200、LENGTH；思考字段53581字符，未返回最终content。不是分块失败，不是本次内容审核拒绝。

上一轮仅将CHUNK输出/等待/租约改为32000/600秒/630秒，SECTION、CHAPTER、BOOK仍使用16000/300秒/330秒，是阶段设置遗漏。本轮消除此差异。

## 最小修复

所有MiniMax-M3书籍文本用途（分块、归并、全书综合）统一由一处常量管理：总输出32000词元，等待600秒，数据库执行租约630秒；Gateway并发占用租约覆盖完整等待。思考保持开启，每请求仍最多1次。其他提供商、Embedding、音频、OCR和视频不受影响。冻结路由和历史回执不改写；新请求指纹体现新输出设置。

不接受截断结果、不本地修补JSON、不自动重试收费请求。新增回归确保综合某批次截断后，已有成功批次会命中缓存，只重新生成尚未完成的工作。
