# 百炼密钥验证修复（2026-11-06）

## 根因与修复

原验证逻辑只有固定供应商验证地址，没有百炼工作区专属模型目录地址。前端验证请求也未携带已填写的百炼区域、工作区配置，因此返回“不支持自动验证”，并非云端判断密钥无效。

前端现将区域与工作区配置随验证请求提交。服务端使用既有白名单区域与工作区格式校验，要求调用地址与配置精确一致，推导同一官方主机的 `/api/v1/models` 地址。仅发送 GET，禁止重定向，不发送模型生成请求，不保存测试密钥，不自动绑定用途。

HTTP 200 仍须满足 `success: true`、`output.models` 数组和非空型号标识校验。认证拒绝、网络错误、超时沿用现有安全状态；供应商原始回执不向页面或日志透传。
