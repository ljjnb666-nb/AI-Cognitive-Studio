# 个人数据生命周期：实现范围与删除约束

## 已实现：账户与个人学习记录导出

账户设置页提供 JSON 下载，接口为 `GET /api/account/export`。身份只来自服务端当前 Better Auth 会话，不接受客户端指定的用户或工作区。该账户接口不要求 Beta 参与资格，也不会自动创建工作区。

导出格式 `acs-personal-learning-records` 版本 1，包括明确字段列表中的账户信息、成员角色、认知收藏、复习状态与事件、个人思考会话/消息、复述及评估。消息与评估通过其父记录的用户归属查询；同工作区其他成员的个人记录不可见。默认返回附件，禁止缓存。

共享书籍与认知正文、原始文件、生成媒体、Beta 活动/反馈以及身份和供应商密钥不在该格式内，文件中明确列出排除项。因此这不是完整工作区备份或完整个人信息访问请求的交付。

所有查询在 PostgreSQL Repeatable Read 事务中完成。读取正文前，数据库按导出字段白名单计算 JSON UTF-8 体积；超过 20 MiB 时直接拒绝，不把超大正文传入 Node.js。最终文件仍单独检查实际 UTF-8 字节数。数据库表示和最终 JSON 表示略有差异，因此接近上限时可能保守拒绝。同一账户只允许一个进行中的导出；事务结束即释放锁，其他账户不受影响。单次上限为 10,000 条相关记录和 20 MiB UTF-8 JSON；超过上限返回 413，绝不返回截断后标为成功的文件。大账户的分块导出仍待实现。未登录返回 401、并发导出返回 429、后端失败返回脱敏 503。界面显示错误并允许重试。

## 已实现：单份原始文件下载

书籍详情页提供“下载原始文件”，接口为 `GET /api/studio/sources/:sourceDocumentId/download`（也支持 HEAD）。以当前服务端会话的工作区查询文件记录；其他工作区返回 404，且不访问对象存储。对象键不下发客户端。

下载复用带取消和长度校验的流式传输，支持单段 Range。响应强制附件、禁止缓存并设置 nosniff/CSP sandbox，避免上传的 HTML/SVG 在应用源内执行。下载名保留合法 Unicode 并过滤控制字符和路径分隔符。真实浏览器已验证下载文件与原始上传字节的 SHA-256 一致。

此功能只下载单份上传原件，不包括理解结果、生成媒体或完整工作区归档，也不改变下述删除限制。

## 删除仍未开放

当前 `WorkspaceMember` 是个人会话/复述的归属边界，而 Source/Blob、理解结果和音视频归属于共享工作区。用户是工作区成员不等于该用户独占这些文件。删除账户不能直接级联删除共享工作区，移除成员前也需要确定个人记录保留策略。

完整删除必须先建立持久化删除请求与状态，冻结相应范围内的前台写入、上传完成、任务领取/恢复及外部付费请求；再逐对象清理并验证原始文件、临时上传、音频/视频/供应商结果与衍生索引，最后删除 SQL。清理前必须列清对象键的实际所有者，不能用未经验证的前缀代替归属检查。

尤其需要覆盖 Worker 已领取任务、外部 Provider 请求正在返回和预签名上传仍有效三种晚到写入。仅检查一次会话或仅取消 Job，不能证明外部存储不会复活。失败阶段应留下不含原文/凭据的持久化重试回执，重试不得越租户。当前未实现这些约束，所以不会在界面提供看似成功的删除按钮。

验收须包含真实 PostgreSQL/对象存储的并发写入、部分清理失败与重试、跨租户隔离、已删除数据不复活，以及最后 SQL/对象双重检查。现有临时上传清理回执不等于完整账户/工作区删除。
