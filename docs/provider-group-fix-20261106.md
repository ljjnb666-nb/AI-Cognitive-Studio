# 服务商重复展示修复（2026-11-06）

问题来自上一轮适配：配置向量、语音用途会生成固定端点的内部连接，接口响应却把内部连接作为独立服务商列出，并展示了内部编号。

- 服务商列表和用途下拉框统一显示原服务商；内部接口用“已配置用途接口”摘要展示。
- 通过固定端点、协议、工作区与父记录身份识别受管理连接；兼容旧版生成名称，新记录增加明确关联标记。用户独立创建的同品牌服务商不合并；缺失合法父记录的连接不会被隐藏。
- 原数据库连接、用途绑定、冻结快照与历史回执保留，读取不重写历史；重复保存、并发保存复用同一内部接口。
- 密钥更新、停用/启用、撤销与删除在事务内管理关联接口，防止隐藏的接口继续独立生效；旧确认发生变化则拒绝写入。创建接口与父记录管理共用行锁；发现归组范围改变即停止并提示刷新。
- 管理操作保留 OWNER 权限和固定端点限制；保存配置与回归均不调用真实模型。
