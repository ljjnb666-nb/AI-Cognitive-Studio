# PDF 来源页核对界面 v1｜第一条可见的真实书页审查通路

**2026-10-28｜Draft / 只读；不代表已经完成人工审核**

## 唯一交付目标

书籍详情页现在对 PDF 显示「核对 PDF 来源与物理页」，点击进入：

`/studio/library/[sourceDocumentId]/review?page=0`

这个入口读取当前 `CurrentDocumentExtraction` → `SourcePage` → `SourceBlock`，并展示**实际已经入库**的 PDF 物理页和文字区块。不是构造演示数据，更不是读取静态五书 Benchmark 包。

## 安全和来源规则

- 必须先通过现有 `sourceDetail` 的工作区 / 用户身份鉴权；未授权或其他格式返回 404。之后才依据该源文档当前的 `extractionId` 查页和区块，不得跨工作区用任意 ID 查询原文。
- PDF 物理页 URL 使用 0-based `page`，页面显示 1-based 物理页；无页映射时明确标注“无对应存档页”，不能推测是空白页。
- 当前页最多取 17 条区块用于判定是否超过预览上限，展示最多 16 条、6,000 字符。严禁将预览误称为整页核验；显示原书 SHA256 和当前解析器版本、预览截断与总区块数。
- 不能把解析成功、已入库的文字当成独立 Gold；不自动向 `BookIntelligence` 或播客写入审核意见，也没有“批准”按钮。
- 视觉图候选在 #208 中只由显式 opt-in Worker 以内存形式返回，**没有网页可读取的持久化审核回执**。所以本页面图表区域仅显示“尚不可审核”，绝不生成/伪造图的节点、关系、模型置信度或人工审核状态。
- 这项功能没有新 provider/model 调用，没有 API key 处理或外传原书，不改变 Docling 生产开关，**没有任何写入数据库的动作**。

## 验收限制和后续

本 PR 通过同一准确 HEAD 下的读侧 DTO 安全/截断测试、Web TypeScript 和 ESLint 评估；完整主 CI 必须独立核验。专项测试并不能证明浏览器中真实登录/权限交互或真实书籍端到端审核已经过 E2E 实测。

**这个切片一旦通过专项 CI，立即停止扩展。** 后续的唯一优先切片是：视觉 Worker 产物的可授权、安全、短期保存与读取机制，随后才允许用户在同页 UI 查看图节点和原图，并实现可撤销/可重审的人工核验状态机。在独立原页证据未充分验证之前，任何“已审核”状态均不能推动播客事实发布。
