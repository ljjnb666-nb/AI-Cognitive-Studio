# 已提取正文无法阅读修复

## 根因与范围

原详情读取逻辑只从当前正式提取结果的页面记录生成预览。EPUB、TXT、Markdown 通常只保存正文区块，不保存 PDF 式页面，因此即使提取成功也返回空预览。该缺陷影响无页面记录的提取结果，并非 EPUB 文件损坏；有物理页面的 PDF 仍沿用原路径。

只读核对当前用户 EPUB：已正式发布的提取结果状态成功、298746 字符、2334 区块、0 页面。没有重新提取、改写正文或触发模型。

## 最小修复

仅修改 `sourceDetail`：当前正式提取成功且无页面、有区块时，按区块序号每 40 块分段返回；页码夹取到合法范围。预览标记为正文分段，不伪造 EPUB 物理页码。已有 PDF 逐页读取、40 块及单块 4000 字符预览上限保持不变。

访问限制仍要求当前工作区、未归档文件及当前正式提取指针；未发布、失败提取和其他工作区数据不进入阅读预览。无需等待 AI 理解完成，不修改历史提取、分析任务或数据库结构。
