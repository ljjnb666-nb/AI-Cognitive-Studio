# 单书分块并发设置验收（2026-11-06）

## 已实现

在“设置 → AI 服务商设置 → 理解并发与资源额度”增加“单书分块并发数”，可选 1～4，默认 2，1 为串行。只有工作区所有者可以保存。每次任务启动或恢复读取一次，不动态改变在途请求。底层显式注入提供商的旧调用默认仍串行。

配置唯一存储在 WorkspaceResourcePolicy.bookChunkConcurrency；旧客户端遗漏新字段时保持原设置。数据库和接口均拒绝超范围数值。迁移仅新增字段及范围约束，已在隔离测试库及本机开发库应用，不改写历史 Run、RoutePlan、模型回执或费用记录。

分块池达到设定数量后等待空位，原引用范围、操作幂等键和持久化序号不变。首次失败停止派发新块，等待在途请求成功结果完成持久化后再将任务置为失败。不增加重试，也不放宽审核、引用和预算门禁。章节归并与全书综合保留顺序依赖。

修复租约续期被较短续期覆盖的问题：以数据库时间计算新期限，并与当前期限取较大值；错误所有者仍被拒绝。
